Good to know

Quick answers.

Useful details for visitors before they join the community or download.

Where do I download Anubis Client?+
Downloads are posted in the Anubis Discord and linked from the download button on this page. Always grab the file from an official source — reposted builds are not something we can vouch for.
Is Anubis still in beta?+
No — Anubis is on the stable 1.0 release, and every update ships through the Anubis Discord.
Which Minecraft versions are supported?+
The current release targets the mainstream client versions used on DonutSMP. Version support is listed in the release notes alongside each download.
How do I install it?+
Drop the client into your usual Minecraft setup, launch it, then open the module menu with the default keybind. Your configs are saved automatically and restored on the next launch.
Can I change the look and keybinds?+
Yes. Every module can be rebound, the menu supports presets, and you can save multiple configs for different sessions.
Where do I get support or report a bug?+
The Anubis Discord is the fastest route — bug reports and feature requests are tracked there so fixes ship in the next update.
